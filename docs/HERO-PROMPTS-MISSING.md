# Hero Image Prompts: Pages Without A Hero Photo

One prompt per page whose hero currently shows no photo: **224 pages** (checked on the production build).

- **Format:** 1600×1000 WebP (16:10). Save under the file name shown in `public/images/incoming/`, then run `node scripts/import-images.mjs`.
- **Layout:** the photo sits behind a dark left-to-right gradient with the headline on the left, so each prompt keeps the subject in the right third and the left side calm.

**Negative prompt (use with every image):** text, letters, numbers, watermark, logo, signature, cartoon, 3D render, illustration, CGI, plastic skin, extra fingers, distorted hands, oversaturated, stock-photo grin, futuristic hologram, robot, glowing brain
